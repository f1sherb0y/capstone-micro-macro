## 与 CASE-0014 一起看

- 两个案例都是 6 个包一轮完成采购、项目关闭，都没有出现此前的卡死。
- 本案多数合同在第二稿就签约，CASE-0014 全部用满三稿。
- 两案都有包按预算上限报价（设计包两案都是 100%，材料包 99% 到 100%）。施工包有三家竞争，报价在预算的 85% 左右；只有两家或一家投标的包报价贴近上限。这是值得在报告中说明的模型行为。
- 候选企业的角色来自情景数据的分配：例如本案造价咨询中标人 COMP-0169 名为“中国建筑第五工程局”，在 CASE-0014 中被分配为设计方。这是候选池的问题，不是本次修改引入的。
