## 1. 固定边界与未决事项

平台限定大湾区，采用八类角色、三类业主、最小资金账本及地区×用途聚合需求；市场与政策参与解释业主自主提出、调整或放弃项目。技术与建造方案在专业和供应意见基础上细化。完整边界以[研究范围](../01_overview/research_scope.md)为准。

“待选择”表示相关研究机制尚未确定，不能用隐含默认值代替；“待填契约”表示职责已明确，但字段、方法或例子尚不足以唯一实现；“待实现”和“待验证”必须分别登记。文档规则的存在不是代码或实证完成的证明。以下事项未提供已选值，具体模型应逐项填写引用，或说明不适用及其解释限制。

## 2. 模型选择登记

### D-01 · 项目机会与正式立项

- **确定范围**：允许业主自主形成提案；固定机会池仅作有明确目的的辅助实验。记录提案、调查、投资、开工的数量、规模、地点与时点。
- **待选择**：用途与需求单位、初始存量、在建信息可见性、需求生成/吸纳、候选地区/规模、评估投入和触发、重复方案识别、土地/资产排他权、正式登记条件，以及改造、租赁、分期等非新建替代的执行范围。
- **落点**：[Owner](../04_roles/owner.md)的 OWN-A01/A16/A02/A03、WORLD-017、OBJ-021 和 P01—P05。期初对象、调查工作和正式项目不能合并成一次自动创建。
- **就绪证据**：在有限需求、资金和载体下，可以产生、延期或放弃机会；相斥方案不能同时获得同一排他权。

### D-02 · 最小资金账本与持续资金来源

- **确定范围**：现金、应收应付、贷款和到期义务由 OBJ-011/012 维护。预算、报价、有效承诺、提款指令、实际收付和清偿分别记录；授信不等于现金，核销不等于免债。
- **待选择**：组织/项目公司/账户归属、币种汇率、产品计息/收费、预付款/保留款、部分付款分配、受限资金、银行执行资金、外部到账及核对、销售/租赁/运营回款范围。
- **持续来源**：三类 Owner 分别声明收入、拨款、外部支付或不再注资的边界。聚合购买预算、信用和交易与 OBJ-017 的共享资金来源一致，不能按项目复制资金。
- **落点**：[共同对象](../02_world/domain_objects.md)、[Owner](../04_roles/owner.md)、[Bank](../04_roles/bank.md)与各服务/供货角色；影响前期研究、P08、P13—P16、P21—P23。
- **就绪证据**：部分执行、直接支付、预付款抵扣、退款更正、重复和未知回执均能核对；债务与到期分期不重复计量；至少跨两个经营周期检查持续资金边界。

### D-03 · 组织身份、多角色与授权

- **确定范围**：组织身份、角色模板、项目职能和授权分开；三类业主是目标模板，不是三家固定组织。人员资源/授权岗位不自动成为个人智能体。
- **待选择**：一个组织允许承担哪些角色，多角色认知是否分部门，利益冲突与有效授权，内部团队和外部顾问的责任；公共业主投资批准与监管许可分别由谁决定。
- **专业及机构**：Engineer 的专业范围、作者/审查者权限和资格分开；Government 按地区与事项绑定实际机构，不由角色分数决定审批权。
- **落点**：OBJ-001/003、项目责任表、八类角色和合同模板；联合体接口还依赖 W4。
- **就绪证据**：同一组织跨项目不复制现金/产能，多个职能各自校验权限；未模拟的个人决策、保险、仲裁等由有界过程承担或明确排除。

### D-04 · 时间、日历与同刻排序

- **候选机制**：统一固定步长；固定汇总周期内处理事件；离散事件为主并定期汇总。未指定日、周或月为默认业务尺度。
- **待选择**：时间单位、日历/工作日、期限、同刻排序、观察截止、去重、循环上限和反馈时滞；案件排队、实际审查、补件、通知、生效、到期和续办的计时语义。
- **落点**：[世界运行](../02_world/world_runtime.md)的 WORLD-027/028、方法目录、项目依赖和运行清单。
- **就绪证据**：业务时间与模型调用耗时分开；墙钟速度不改变工程，技术回复先后不暗定业务顺序；共同冲击只按声明的暴露对象作用。

### D-05 · 跨项目承诺与资源竞争

- **候选机制**：有依据的时间/优先级提交；统一截止后的清算分配；按资源类型采用不同方法。
- **待选择**：承诺/预留时点、有效窗口、投标占用、取消成本、排期修改、冲突反馈、待命与召回；调查档案与正式项目共享管理能力及资金的校验。
- **落点**：OBJ-010、FLOW-007、人员/工厂/银行/通道资源方法及各角色接单行为。
- **就绪证据**：共同资源只有一个有效容量来源，分配可解释；遍历顺序、线程数和网络延迟不成为隐藏优先级。可召回不等于立即有空。

### D-06 · 工程、采购与事项模板

- **确定范围**：目录覆盖建筑（含超高层）、道路、桥梁及声明的扩展对象；目录不代表方法已经支持。工程对象、用途、业主目标、建造方法、采购和回款方式分别配置。
- **待选择**：适用对象/功能/规模域、建设任务和数据；设计责任、有限前期服务与正式委任、承包商介入、采购程序、专业分包和长期设备；正式项目与放行任务需要的授权。
- **融资/审批**：选择适用金融产品、地区/项目/事项、来源与过渡条件、并行或分范围许可。自有资金与单银行非循环安排可以作为候选基准，不作为默认选择；未知许可不能默认为不适用。
- **落点**：[工程模板](../02_world/project_types.md)、角色委任/合同、P03—P15 和事项模型。
- **就绪证据**：一个有方法和失败出口的工程/采购组合可运行；P01—P23 是事项索引，不强制所有项目采用同一顺序。

### D-07 · 有限方案与工程工作粒度

- **待选择**：代表性工作包、工程量、劳动力/设备/产能/材料单位、替代关系、生产率、检查与返工；专业输入/输出精度、工作量、耗时、完成标准和支持方法。
- **方案边界**：模板限定离散选项、数值范围、相容关系和候选数量。两个初始候选加一轮修订属于候选简化方式，不是确定上限；超高层适用方法、改扩建和子工程细度另行声明。
- **专业分工**：编制者按工程对象和委任确定，建筑可由 Architect 与 Engineer 分工，道路/桥梁等由适用专业承担。编制完成、专业通过、客户接受和法定许可分开。
- **落点**：OBJ-006、工程模板、各专业角色、P09 与 P14—P20。
- **就绪证据**：同一方案版本贯通数量、专业核验、QS计价和实际履约；缺方法不允许靠空函数或语言声称成功。F-GBA-01 仅作合成接线基准，不替代真实工程校准。

### D-08 · 市场反馈与政府调控

- **确定范围**：地区×用途需求与存量影响业主提案，订单、资源占用和正式资金状态由业务产生；不新增需求侧个体智能体。
- **待选择**：需求/吸纳/使用、企业报价与总体价格、融资条件、产能进入/退出以及政策的响应范围；各变量是固定、外生路径、内生反馈还是未覆盖，以及观察权限、频率、时滞与依据。
- **长期经营**：选择固定主体总体还是允许企业进入/退出，声明无订单期间的持有、闲置、维护支出及能力变化；可以采用外生过程或不覆盖，但不能隐含为零，也不能据此解释未建模的产业演化。
- **去重**：聚合需求是否包含已建模自用组织需要、同一满足事实怎样关联需求池与供给范围，需要明确；相关身份接口见 OBJ-017。
- **落点**：WORLD-019—021、OBJ-017、企业经营与政策反馈定义。
- **就绪证据**：不重复外生变化和内生增量；不直接调好结果再归因于主体行为。有环境更新器不等于启用 Government 自主调控。

### D-09 · 信息、候选、记忆与学习

- **待选择**：公开/受限/私有范围、授权、传播时滞、候选搜索与排序截断、预期方法、主观评价、遗忘和纠错；认知初态选择全新、指定基线或有意历史继承。
- **确定边界**：正式事实、主观信任和私人意图分开；认知按运行和主体隔离，不因组织名称相同共享私有历史。
- **落点**：OBJ-003、各角色观察和决定、[运行结果](run_and_results.md)的暴露与行为评估。
- **就绪证据**：等价顺序/无义名称扰动、简单行为基线、固定记忆与指定学习对照；记录更多消息或记忆不能单独证明学习有效。

### D-10 · 暂停、失败、退出与责任关闭

- **待选择**：暂停期间资源和现场保护、欠款/担保、重招接续、取消后资产、企业偿付困难与退出；哪些事项可恢复，哪些对象终止后仍有义务。
- **资金边界**：提款条件未满足、到期未清、技术执行未知、补救、展期/重组、未用额度关闭与有效免债分别处理。
- **落点**：项目运行、各角色退出、资金/资源记录和 P17—P23。
- **就绪证据**：工程、使用、移交、缺陷、结算和清偿有独立结束条件；暂停不等于终止，终止和核销不自动清偿债务。

### D-11 · 决策方法与验证范围

- **待选择**：各动作的规则/模型提供者、允许候选、上下文与专业证据、最终接受、技术预算与失败语义；离线基线和真实模型评价范围。
- **确定边界**：建议、最终选择、合法性校验和正式执行分开；默认 Skill 返回结果由宿主提交，多步副作用须采用明确续办协议。平台操作者不自动拥有角色业务权限。
- **落点**：[开发契约](../06_engineering/implementation_contracts.md)、[技能架构](../06_engineering/skills.md)、角色动作和研究验证。
- **就绪证据**：一个行为的观察—决定—提交—反馈完整，拒绝、无候选、无效输出和技术未知可区分；真实调用在明确服务、预算与授权范围内执行。

### D-12 · 政策实例与比较实验

- **确定框架**：来源/条款、机制分流、参数、工具组合、审阅冻结和执行交接；宏观、混合、原子路径分别支持有依据的作用方式。
- **待选择**：真实来源或明示实验文本、湾区方向/事项/用途、时期/条件/过渡、执行能力、预算/资金、参数依据、主要研究问题与指标；对照与重复计划沿正式实验契约。
- **候选起点**：资格范围、程序任务、信息候选、有限资助中选机制贯通，比较制度基准、单项、组合、能力及低响应情景，不预设最佳组。
- **落点**：[政策量化](../05_policy/quantification.md)、[工具目录](../05_policy/instrument_catalog.md)、[运行与比较结果](run_and_results.md)。D-04/05/06/08 依赖独立声明。
- **就绪证据**：能追到配置实际改变的决定、约束或计算；原文核实、机制实现、参数校准和现实效果验证分别有证据。

## 3. 跨模块接口准备

共同类型、具名函数和提交协议已经在 [输入输出契约](../06_engineering/interface_contracts.md) 与 [系统接口目录](../06_engineering/system_interfaces.md) 定义。下表追踪具体模型组合仍须绑定的范围、方法、单位、数据与执行证据；有通用接口不代表每项业务方法已经选定或实现。表中说明就绪标准，不重新定义接口。

| 接口 | 业务落点 | 启用时必须绑定的具体内容 | 确定检查 |
|---|---|---|---|
| W1 世界覆盖与背景业务 | RUN-001/002、WORLD-001、OBJ-021/017 | 实例代表自身或群体；聚合需求中的世界承接范围；未单列业务对供给/竞争及人员、工厂、资金、通道、审批容量的占用；来源、时窗、更新、释放与显式业务排重 | 总覆盖不变时，把显式背景业务改为等价聚合不释放同一工厂容量；企业显示数量不改变同范围需求。不能等价聚合时声明世界范围改变 |
| W2 共享运输瓶颈 | OBJ-020、Supplier、环境资源更新 | 路径引用有序物理段/交接节点/换装任务，共同约束使用同一资源ID；各方向、方式和窗口是否共享容量；关闭/扩容作用于物理资源 | 两条路线共用容量为1的节点时，总通过量不超过1；改名不生运力；节点扩到2后是共享2。数字仅作逻辑算例 |
| W3 资产权利与经营 | OBJ-017、OWN-A14 | 资产范围、权利类型、持有人、有效期间/条件、依据和变更事件；所有/使用/经营授权分立；买卖承诺、付款、交接和权利生效分别接线 | 转售不增物理存量；存续租赁按条款继续或终止，租金归有权方；原方历史债务不因换主自动消失 |
| W4 联合方案与成员责任 | OBJ-008、INST-014、Contractor | 联合方案版本、逐成员接受范围、代表权限、资格/资源、合同/付款主体、退出与重查/再接受条件；按D-03/D-06选模板 | 成员拒绝/退出后不提交其新承诺，不继承或复制其资格产能；已发生费用/义务保留；无履约模板不能由推荐形成联合履约事实 |
| W5 再校验与技术重试 | FLOW-007、开发契约命令协议、Skill宿主 | 区分同命令查回执，与已确定未提交且原决定/授权有效、依赖变化、动作允许时的新校验；新命令带父引用并保留业务对象身份 | 资源释放后可合法再校验但不复制合同付款；未知结果沿原身份核对；决定过期需相应新授权，不自动续期 |

W1 是总体装配的必要条件；研究共享拥堵时启用 W2，研究资产转售/运营时启用 W3，研究联合履约时启用 W4，提交协议实现须明确 W5。未启用分支可声明不覆盖，不要求为了填表增加角色或机制。覆盖不一致造成的短缺不能简单当成真实区域瓶颈；真实短缺也不要求人为调成供需平衡。

## 4. 可采用的有界简化

| 边界 | 可声明的处理 | 不能据此解释 |
|---|---|---|
| 土地/资产取得 | 有限载体清单和有来源授权事件 | 完整地价、竞地与政治决策 |
| 需求与外部资金 | 聚合需求、有限共享预算或明确外生到账 | 家庭信用、存款创造及整个财政体系 |
| 未单列企业/项目 | 有来源、可更新且不重复的背景供需和资源占用 | 完整企业进入退出和产业演化 |
| 物流、检测、争议 | 有任务、能力、费用和结果的过程 | 未建模机构的独立策略行为 |
| 价格、利率、天气 | 外生路径或有依据的受控随机过程 | 未启用的内生宏观反馈 |
| 资产运营与产能扩张 | 固定经营范围、外生能力更新或不覆盖 | 未建模的全寿命收益、交通福利、工厂布局与企业成长 |
| 政策更新 | 指定版本和生效/失效计划 | 未定义目标、权限与反馈的政府自主调控 |

## 5. 实现准备与选择记录

| 准备顺序 | 可交付内容 | 必须引用 |
|---|---|---|
| 研究模型 | 一个明确问题、对象/功能、总体覆盖、支持方法和未覆盖边界 | 研究范围、D-01/03/06/07/08、W1 |
| 可执行条件 | 资金来源、时间协议、资源竞争、必要接口和参数证据 | D-02/04/05、启用的W项、领域规则 |
| 最小闭环 | 同一方案的数量、专业核验、履约、资金和反馈；失败/等待出口 | 角色动作、项目运行、贯通算例及方法预期 |
| 政策比较 | 真实作用入口、可比较初态、指标与样本计划、技术预算 | D-09/11/12、政策和运行结果契约 |
| 前后端交付 | 从保存配置到运行查看、对象证据和正式比较的完整交互 | 前端规范、软件模块及验证策略 |

对每个选择登记 `decision_id`、状态、适用问题/范围、候选、所选方案及理由、依据/假设、参数/单位、依赖规则、影响文件、负责人、决定记录和验收引用。改变模型含义需要留下新的配置/方法版本，不能只覆盖旧实验结果。状态至少区分待选择、选定待填、方法就绪、实现可用、验证范围明确；不把它们压成一个完成百分比。

实现登记按能力记录规则引用、代码与schema位置、方法/输入、实际检查、限制和证据；没有执行证据的项保持未验证。可以先开发不依赖未决模型的身份、账本、提交、只读页面和隔离契约样例，不能用这些局部完成声称整个世界已经可运行。
