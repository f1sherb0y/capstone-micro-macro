## 1. 场景范围与主体

研究地域是大湾区。本例观察香港某类建筑用途的潜在需求，业主可同时调查湾区内其他地区的备选；某条候选路径采用佛山生产设施向香港项目供货。其他湾区项目可以同时争用这些专业人员、资金和制造能力，并非等本项目结束才运行。

以下 ID 全为虚构示例；角色来源并不证明任何实际企业有权在相应地区执业。

| 身份 | 本例的职能 | 实际授权怎样落实 |
|---|---|---|
| `owner_HK_01` | 投资收益型业主，形成提案并承担自己的承诺 | 投资、委任、借款及支付各有范围；不取得他方权力 |
| `bank_HK_01` | 独立审查并提供可选择的融资安排 | 产品、资金来源、受益人及支用条件在场景内明确 |
| `architect_HK_01` | 受托转译需求、编制方案与建筑接口 | 有效服务范围和用途发布权限，非默认总批准者 |
| `engineer_SZ_01` | 候选专业服务方 | 深圳身份不保证香港项目资格；须先核对本例事项/范围的适用依据，未满足可拒绝或改选 |
| `qs_HK_01` | 成本计划、采购意见及获授权计量核证 | 有权范围、数量与价格依据、不同意见及未覆盖项分别保存 |
| `gov_HK_case_01` | 某明确事项的有权机关实例 | 本例不代表香港所有机关；其他事项另有职责绑定，不能一项决定全部放行 |
| `contractor_HK_01` | 独立投标并履行总包合同的候选组织 | 通过有效接受形成限定责任；未选中前没有施工承诺 |
| `supplier_GBA_01` | 使用 `factory_FS_01` 的供货候选 | 注册地另行记录；实际工厂、能力、订单及运输责任分别存在 |

一个角色可有多个竞争候选。场景先给足候选数据和适用规则，再让相应主体选择，不能按本表 ID 顺序强制指定合作团队。

若在此场景测试资格或证据工具，先指定源地→目的地、专业/产品/事项及有效证据；Engineer 或 Supplier 的地区标签不直接满足资格。若测试资助，则另外实例化真实来源、预算、获授和付款规则。与基准比较时允许业主选择不同方案或不投资，不强制该示例项目在所有情景成功交付。

### 4.1 同一物理范围的合成贯通例 F-GBA-01

本例的稳定 `fixture_id=F-GBA-01`，定义一条可手核的“方案—数量—制造—运输—检查—安装—交付—付款”链，修复分支沿同一件产品接续。它是**用途无关的代表性交付物局部接线基准，不是首个完整研究模型 profile**；不选择住宅、公共服务或自用建筑，不与上表 260 m²、10 件或资金子例相加。真实用途、完整建筑方法与研究基准配置仍待选择。

所有主体选择、授权、业务接受和付款决定均由固定离线输入给定；本例不要求真实模型调用，也不构成真实模型行为的验证证据。专用 `TU` 为测试时间单位，`FH` 为测试劳动小时，`CU` 为单一虚构货币；规定下面各窗口可提供的 FH，不推定 TU 与现实日/月或 FH 的普遍换算。所有金额无税、汇差、融资、预付款、扣留款或利息；没有最终用户购买、区域吸纳或贷款。这些是本例的支持边界，不删减平台已确认范围。

| QS 有计量依据但 Owner 当前缺钱 | 到期支付及现金安排 | 提款、调整自身支付、协商、条件内部分付款或补救 | 应付、已做工程和各方独立决定；不能自动使 Bank 接受贷款 |
| 模型超时或执行结果未知 | 本次技术请求或执行核对 | 保留待办，恢复响应或核对既有事实 | 不能伪造业务拒绝/接受，也不能重新派发可能已完成的同一执行 |
| 政策或项目方案发生变化 | 被该版本/范围直接影响的任务 | 按适用规则复核、补件、调整或续办 | 原决定所见信息与既有事实；未受影响范围不全部重置 |
| 项目暂停/换承包商 | 新作业、资源保留和移交范围 | 有权方决定保护、接续、重新分配或终止 | 原作者、原欠款、在途、未决结果和没有被有效转移的责任 |
| 观察期结束但仍有贷款或缺陷 | 运行观察范围 | 输出截点状态，不再擅自推进超期结果 | 未完工作、债务、后续责任和未成熟指标；不强制关闭 |

暂停不冻结整个世界。其他项目照常竞争资源，报价可能到期，债务可能到期，适用保管/维护任务仍有投入和费用；是否违约以及如何补救由明确条款和程序决定。

## 6. 经营与环境反馈

一次交付首先改变真实资产/可用范围，再经明确聚合过程改变实际使用和需求满足；然后形成有截止时点的地区观察。Owner 可能减少提案、转向其他用途/地区，或仍因错误预测继续投资。既有自用需求与地区聚合的覆盖关系决定如何去重。

实际合同、排期和现金变化改变各组织下一轮接单、报价、授信和施工安排。一次合作经历能进入相关主体的私有经验，但各方不必有相同评价；不能从项目同现直接生成互相满意或长期联盟。

Government 可在其信息权限内读取事项和区域结果。若实验只给外生政策路径，它继续处理行政/监管职责；只有明确启用内生调控时，才按新增工具权限、反馈时滞和决定契约修改政策。不能用仿真器为了让结果好看而偷偷调控。

## 7. 完整研究基准的装配条件

本文件覆盖责任、对象、依赖、异常和反馈；第 4.1 节定义限定范围、固定选择的合成计算链。完整研究基准还需填实用途/需求单位及覆盖、建设载体条件、专业方法及方案到材料/工作包的转换、地区事项模板、产品/币种与实际资金来源、业务时间与竞争规则、价格/生产率等参数证据。

选定这些内容后，用一套有来源或明确合成的初始状态，把上表交接绑定到具体对象和动作；补每次执行前后的精确状态、等待/拒绝结果和数值预期，再开展实现。其它地区或项目模板可以逐步增加，不需要为首个完整基准模拟整个社会。
