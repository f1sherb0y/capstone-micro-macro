# ENGINEER-A03 核对委任和检查独立性

沿原 Appointment、ENGINEER-A02 RecordedDecision、ServiceTerms 和本组织职能权限核对独立接受、专业、责任、成果用途、委托/付款关系和当前资源。委托方选中不代表本方接受；更换 agent_id 不改变真实组织关系或原作者。未知资格、作者、关系、必要独立性或当前预留资料保留 needs_information。

读取原 IndependenceRequirement、IndependenceCheck、完整当前 OrganizationRelations、原成果作者和实际适任人员。检查原记录作者权限、时点、同版条款、模板及完整被核对资源集合。原组织/人员重合按声明模板检查；已知冲突须有准确原 ConflictOfInterest 引用，disclose_conflict 保留原问题、接收方和应答要求。作者未知不能编造独立通过，组织冲突已知时仍可披露已知范围。未支持模板和方法保留 unsupported。

专业能力/资格/方法按地区、专业、职能、用途和责任分别检查，不因设计委任获得独立审查、合同核证或其他专业签署权。只选择原适任人员；同一人员不复制成多份容量。共用精确固定地点半开窗容量方法核对当前占用，原预留逐物理资源排重，不释放其他承诺。过期、不相容条款或资源变化使用 request_amendment。

confirm 仅保留原委任和独立接受条款；已建关系与已转换预留沿原身份核对，不重复创建合同或占用。completed 不登记正式关系、资源转换、任务/投入、签署或专业通过。正式生产者/提交/查询、A04 交接、回执和反馈仍由宿主服务核验。
