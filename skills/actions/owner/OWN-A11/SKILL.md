# OWN-A11 履约指令、变更与分项争议

仅读已成立原Contract、当前有效ContractTerms、己方原OwnerContractDecisionProfile与独立Authorization；合同事实、承包商成本、专业意见、变更提议及付款分别保留性质。原CommittedEvidence核对原已记录工程/检查/核证/事件身份和摘要，技术失败不编造成工程结论。

instruct/verify/remedy明确受影响部分范围、原Requirement、原独立专业/监管/权利等条件和增量预算。有资金投入的工作逐原FundingSource实际现金减受限余额及当前跨项目预留核对，不用未来现金。verify可请求核实未知条件，不假装已经满足；资金不足只阻塞相应请求，不全项目停工或删除旧付款义务。

agree_change只作Owner对原ContractChangeProposal及完整同源新ContractTerms的决定；原合同/对方/范围/价款/时间/条款和旧义务保留。仅成本超支不是调价依据，须原合同变更依据、全部必要独立核算和精确己方审阅摘要。已有对方接受核对同run/条款摘要/权限/明确结果；尚缺必要接受保持待定，不能因Owner选择单方更新合同价或自动取消原义务。核心再次核验独立接受与资源/资金竞争才形成变更。

dispute/accept_undisputed逐原ClaimComponent及ContractIssue明确范围；无争议接受须原合同允许、原已记录权利依据及独立专业核算金额一致。不把未核证金额当已付款，不将原本金/成本提议直接增加应付，现金支付另走OWN-A06。分项争议不默认全项目停工，不抵消未选中组件。

completed只表示己方可提交决定，不创建施工放行、批准、付款、债务注销或正式变更。CHECK-OWN-011/015/041/057待集中验证。实际合同/事实/核算/依赖/账户生产者、跨动作投影兼容、正式submit/query、原子变更/承诺及回执反馈仍待集成。
