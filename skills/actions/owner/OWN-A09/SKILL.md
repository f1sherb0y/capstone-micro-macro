# OWN-A09 组织招标与比较投标

首次发布只能使用 preparation 上下文：原范围、已提交且获准采购用途的专业成果、真实数量依据、规则、要求、时间窗及评审模板。生成完整包件草稿，核心才分配包件/轮次身份，不伪造前置包件或投标。其余分支只消费 published 上下文的同版包件、完整可见轮次/投标人/报价。

按原评审模板明确顺序决定 publish_package/invite/clarify/revise_package/evaluate/negotiate/cancel_round/retender。邀请核对真实组织与原资格/权限；投标由原Contractor/Supplier独立提交，版本、有效期、包件及轮次保持。投标前可围绕包件/原询问澄清，不要求先造Bid。回复按原规则核对许可及应公开接收者，不披露竞争者私有资料或隐式改价。

所有作者授权精确绑定RoleAssignment.function_ref，grant/function的basis_refs按原种类有权解析：Evidence核适用时点，其他来源保原类型并纳入来源引用，不强制当Evidence。原Contractor A02/A03或Supplier A03投标作者的授权及Evidence依据按真实submitted_at核，授权覆盖完整bid.scope；当时无权不能以后来权限追认，当时有效而现在到期不否定原提交。submitted_at须同业务钟且不晚于available_at及本次时点，接收交接同核原决定≤提交≤可获≤当前。当前业主评审/采购权限、投标使用窗、当前资格/合规/价格风险及其依据仍按当前状态检查，不从历史作者授权推出当前有效资格或授标。

评审选择同一已截止且仍可授标的原轮次，核对资格、合规、原价格/风险和相同计价依据。未知资格/合规/资金保持缺口，技术未支持不变废标；预测不是采购支出权。原完整授权预算扣除已有真实承诺，不释放原占用。ranked_bid_refs 中每个投标都须在当前 CandidateSet 中明确允许 evaluate，可见及原轮次归属不代替候选权限。零投标/全部不合格/全部超额度可返回空入选列表，不强选；拒绝列表仍保留原范围及业务依据，不为填候选而删改。排序由显式权重/尺度/单位的宿主纯方法执行；并列组保留，无严格唯一胜者或授标。

议价只围绕原收到的投标及问题，bid_ref 必须在当前 CandidateSet 中明确允许 negotiate，不以输入可见代替候选权限，不替对方接受新条款。修订/重招沿完整原版关系、替代/续办/合法并行规则和FLOW-018处置：明确原轮次停止收件/授标范围、时点、待选、临时预留、原通知计划和迟到接受依据。通知覆盖受影响原投标人，预留只沿独立释放依据；旧合同和费用保持，不凭新ID或取消轮次解除。

completed 仅为本地主体招采决定，不发送通知、创建合同、替他方接受、释放预留或改变资金。CHECK-OWN-009/010/057待集中验证；实际成果/资格/投标/资金生产者、包件与轮次/通知/评审登记、正式提交/查询/回执与反馈仍待宿主绑定。
