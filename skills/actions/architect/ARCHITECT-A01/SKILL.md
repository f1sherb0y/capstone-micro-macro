# ARCHITECT-A01 发现业务并选择是否研究

核对原 Opportunity、己方 Strategy 与 ResourceCalendar，按原显式策略选择 ignore/track/express_interest/prepare/clarify。来源或需求不明确保留原问题；兴趣只交原邀请人，不发送消息、不形成收入、能力、合作或委任。跟踪引用原有效 Trigger；允许不参与。

有限准备支持 organization/assessment_case scope，不强制项目已成立、全团队或完整设计。prepare 必须沿原 PreparationRequestProfile 与独立 Authority，核对组织/职能、机会、用途、输入、问题接收者及当前剩余预算/工时。成本/工时估计来自同输入、同方法、同工作模板的已保存成功执行，方法支持地区/专业/对象；失败执行保持技术故障，不转商业拒绝。

有 WorkProfile 时用宿主 micro.capacity.fixed_location 精确比较原排期：完整当前资源、全部原委任占用、原单位/地区/时钟、未来半开窗与生产率。旧占用不移除，不因新客户收益高抢占。额度或容量不足可沿原策略忽略/跟踪/澄清。无工作方法允许 null 与未知工时，只提交受限申请，不执行、不占资源、不形成收费；预算仍须有原估计及独立额度。

问题保留原目标、范围、证据、回应要求及授权接收者，不替客户或其他企业做决定。completed 仅为本主体的机会决定或任务申请；真实机会/估计生产者、准备任务创建、资源登记、提交/查询及反馈仍待宿主绑定。CHECK-ARCHITECT-001/035 待最终集中验证。
