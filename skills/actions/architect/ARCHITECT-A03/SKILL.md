# ARCHITECT-A03 确认委任范围并承接任务

核对原 Appointment、ServiceRequest、完整 ServiceTerms 和已收到的 ARCHITECT-A02 RecordedDecision。委托方选中不是本方接受；原作者、组织、权限、作用域、条款版本及完整摘要必须独立一致。委托人和付款人从原请求读取，承包商委托不默认读取业主资料。内部职能核对本组织任务授权，不能制造对自己收费。

本方拒绝或原委任明确不相容可 decline_incompatible。条款/排期失效、不相容、容量变化或原预留不适用时 request_amendment，问题仅来自原授权 EvidenceTarget 和 ResponseRequirement；不自动替换条款。未知/缺失接受、权限、资料或完整当前资源快照保留 needs_information，方法不支持和技术失败不作为商业拒绝。

复用登记的精确固定地点半开时间窗容量方法。原已预留占用按原 commitment/resource/version/window/quantity 逐项核对；转换时从现有占用排除原项再检查同一物理资源，不新增第二份需求或释放其他承诺。无原预留则核对新需求与当前共享容量。已建立关系或已转换预留沿原身份核对，不重复创建合同或占用。

confirm 只输出原 Appointment 和 accepted_terms_ref，表示本地相容决定。正式服务关系、任务、原子预留转换、资源投入、回执及反馈由宿主提交/查询服务完成；completed 不能代表已建立合同、开始任务、创造收费或取得建设用途。
