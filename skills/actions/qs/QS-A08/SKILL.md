# QS-A08 计量、核实支付申请或获授权核证

核对原合同、本QS的A08计价职能、独立付款申请、范围/期间的真实工作量、原合同单价和独立付款条件判断。工程师意见是原范围证据，不自动满足付款条件。原结果缺失使用原问题request_evidence；成功保存的登记方法、输入摘要和作者原读权必须精确相容，失败结果保留技术失败。

verify只形成核实意见。未知付款条件保留未知认可金额，不凭项目资金核准。certify另需独立核证权限、同版申请、完整statement摘要和唯一原证书业务身份。correct_certificate另需纠正权、原有效证书及相同义务身份，不新造第二笔累计义务。重报已有业务身份先查询。

原数量/价格同单位币种复核、half_even总额取整，本期和累计口径分开。原有效证书历史完整、序号和业务身份唯一；累计原总额只提本期差额，增量不重复原实物工作。保留金按原比例/全合同上限及历史已保留量计算，更正沿原量和净额调整；独立扣款有原权限和依据。超过当次可抵额度需另信用/退款决定。

预付款沿原到账事件、信用额度和完整已用分配历史核对；已抵扣信用不得再次扣款。现金事件、命令/业务键和原执行一致，重复事件一次，累计不倒退；预付现金单列信用资金，不能再当已核证现金扣减。原已支付现金持续保留，未知支付可见性不等于零支付，超付单列，不擦现金。

本处理器不转现金、不改账本或停掉有效工作义务。宿主仍须接入原来源生产者、跨动作投影、正式提交/查询以及原子义务/证书更正/信用分配与反馈；历史重算、信用释放和跨局部范围支付分配须集中集成验收。当前为已编码未功能验证。
