# QS-A05 准备量价与采购成本资料

读取原采购范围、获授权业务任务、所选采购模板、轮次、设计、计量规则、已登记量表和计价规则。版本、用途、原作者、职能和授权一致才 prepare；缺量表可 identify_gaps，不能编造 QuantityScheduleRef 或未设计工程量。暂定数量只有采购模板、计量与计价规则共同明确支持时保留 unknown 及原问题；普通方式不强制填零。

费用包含/排除与设计覆盖一致。方案/量表修订不得沿用未重新审查的同版计价规则；原 RevisionImpact 必须列实际受影响包件、原数量行和当前拆分/合并行，保留前序关系。采购轮次变化必须重验全部版本及原问题的同轮来源，旧澄清不能无条件复用。旧文件及已发布文件保留，不在草稿阶段修改。

发布使用采购范围链接的已保存 ProcurementDocument，逐项核对本次原版本、作者、内容摘要、独立买方授权与 PublicationBasis 用途检查。无独立发布权或授权未知/失效，只能 request_publication 给原采购人。尚未保存 draft 不得发布；用途检查缺项返回原问题。重复引用或续办沿原文件身份提出核验，不生成第二份正式文件、资源或收费。
