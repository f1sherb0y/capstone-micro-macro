# QS-A03 确认委任并安排实际任务

核对原 Appointment、QS-A02 独立接受、完整同版条款、委托/付款及内部职能权限，当前专业责任、用途、资格和利益冲突检查。客户选择不替代本方接受，内部职能不产生组织对自己的服务费。过期或不相容范围使用原问题 request_amendment，技术故障不记成业务拒绝。

task_refs=[] 时可单独 confirm，不虚构 Task、资源分派或已完成工作。有真实授权任务及明确 work_profile_ref 时才 confirm_and_plan；已有原 WorkPlan 和 ResourceAllocation 时 revise_plan，保留原任务、剩余工作、前置条件及占用身份。任务、原条款、职能、地点、窗口、工作量和当前完整共享资源需一致。方法未知/不支持不猜测，等待条件或容量不足输出 deferred。

复用登记的精确固定地点半开窗容量方法。按实际人员身份防止重复容量，按原声明资源份额和生产率计算剩余工作需求，逐资源汇总全部同时任务与其他承诺。续办排除本次明确替换的原 allocation 占用后重验，不排除其他项目。原报价预留必须精确匹配当前占用，转换不能新增第二份需求。不能以应收款、模型输出或报价代替实际任务和投入。

委任确认和资源分派是两个分别提交/查询的宿主命令。completed 的计划只表述待核验决定，不表示两者已成功、实际已投入、核证权或收费已形成。实际生产者、原子资源转换、回执和后续反馈仍由正式服务核验；已建立关系沿原身份续办，不重建合同。
