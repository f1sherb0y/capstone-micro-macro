# QS-A10 申报本企业服务费并收款

本动作只处理本QS企业原委任、收费条款、实际投入、费用计算、应收申报和原收款历史。本企业顾问费与客户工程款核实/核证严格分开；独立QS-A10职能和原权限绑定本企业/经办人/范围，结构相同不赋予工程师权限。内部服务或本组织向自己付款只归集实际成本，不形成外部服务费。

claim/correct须原成功计算、条款条件和真实投入，按声明固定/阶段/预付或投入×单价half_even复核；专业成果通过不替收费条件。原业务键、投入身份和历史完整性排重，条款gross限额在预款抵扣前核算；更正保留原收款、已用信用及真实付款人。信用沿原预付申报、真实到账、原信用身份和已用目标核对，净0只表示全额有据抵扣，超抵扣另退款或留存信用。

dispute/reconcile/remind可无新计算，使用本方原申报和真实回执。核对事件、执行、命令、业务键、累计/增量及账本已认事件；同event一次，累计不倒退。未知/失败付款不当到账，账本认款和真实现金分别保留。只对已确认逾期未清的原应收催收，有到账待核认或未知付款先核对。历史收费条款过期不抹原应收；独立外包到期义务不因客户未付费清零。

completed只是待提交决定，不直接改应收、现金、信用分配、客户核证/结算或已交成本估算；不自动暂停有效义务。正式来源生产者、跨动作投影、submit/query、原子应收/更正/信用/清偿/退款及反馈仍须接入。当前已编码未功能验收；只支持原单币种、声明固定/投入收费和显式原信用，无税汇率推断。
