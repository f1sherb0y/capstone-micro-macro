# SUPPLIER-A11 变更、返修、替换、退款及索赔提议

当前订单/批次/库存/新投入及提议数量、金额依据核当前Evidence有效窗；采购方程序、变更提议、偏离、处置权、任务计划及保存估值记录的依据按真实authored_at，原作者授权精确匹配FunctionAssignment、角色、动作和完整scope，Evidence类型basis按原行为时点核，其他basis保原类型有权读取。样本量依据按observed_at；发生/签发不晚于可获且与当前同业务钟。物主/现场授权数量依据各按其authored_at，权利本身仍须当前有效，不能以旧证据当前到期抹掉原有效授权。

MaterialUse/MaterialRemoval、Transaction/RefundExecution缺实际发生字段，历史消耗/拆除、已收款/已退款金额及未知执行保有权历史读取，不推造available_at/as_of为发生时间。旧请求/变更请求的Evidence可含后续状态，保历史typed读取，原作者授权依据仍按authored_at；当前请求状态和新增依据不由历史身份推定。保存估值的量价/固定额/扣减及直接Evidence来源按saved.authored_at，当前重新计价仍走原MethodRegistry当前依据门。正式请求/退款续办profile升v2，分别核原调用/新调用Evidence及作者依据；当前终态query仍要求真实observed且当前有效的native证据和独立认证，不自动迁移旧条件、不抹掉已退/未知占用。

核当前供应商权限、完整原订单/受影响和未受影响范围、实际批次/现场消耗/缺陷/变更请求和原业务历史；按采购方原有权程序及期限选择六分支。重复业务沿原请求续办，保留未受影响履约及质量责任。变更绑定具体原订单行、要求与偏离，只形成提议。

原缺陷须关联精确批次、物理批次身份和实际观察/检验，观察范围覆盖缺陷范围，原 observed_at 与业务时钟一致且不晚于 authored_at。观察的来源依据须明确为 observed，statement/assumption 或 inferred/assumed 依据不升级为实际缺陷；缺实际依据请求资料。历史资料可迟到，不能用 available_at 替代实际观察时点；现场观察保原安装地点范围，不强制改成工厂批次范围。原装配保存全部实际供应的授权投影，保存结果复用同一来源关联核验，不补造缺失观察。

repair/replace核实际物主及独立现场处置权限，按具体物理切片和明确原权限累计数量；已安装品以实际安装后的物主为准，不混算现存库存。原拆除记录扣实际已移除量，同切片多任务仅在明确先后关系下复用，不删除原消耗。原方法/配方/自有资源/时间窗核对；新增投入绑定实际原预留库存或有权采购需求，拆除、退回运输、新供货、再次安装分别留任务步骤及依赖，不生成实际库存或完成记录。

propose_refund指原采购方实际收款交易、完整退款历史及已退余量；未知执行先查询，退款提议不执行负付款。claim按原订单行/具体问题依据提出，可尚无收款交易；可选交易必须为原实际收款。金额未知保留unknown；已知金额核原有权估值作者、来源时点/读权/输入摘要/保存报告及同币种精确量价扣减。该方法只是明确来源金额算术，不判断法律责任、推断损失或形成债务。decline_request仅拒绝已收到原请求，不免其余义务。

本批仅编码和静态检查，尚未功能验收。真实投影生产者、跨动作投影兼容、正式submit/query、核心实际退换/新增投入/退款及费用调整、回执反馈仍待集成。
