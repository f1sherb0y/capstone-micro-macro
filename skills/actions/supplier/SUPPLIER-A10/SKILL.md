# SUPPLIER-A10 提出收款并管理自身付款

当前资金/预留/义务/组成余量、新请款金额与重新计价方法依据核当前Evidence有效窗。原付款节点、节点委任、保存计价记录及作者依据按真实authored_at，交付依据按occurred_at，发生/签发≤可获≤当前同业务钟；精确FunctionAssignment/角色/动作/完整scope与原时点授权有效，混合basis保原类型读权。节点委任覆盖完整节点scope且签发不晚于节点作者行为，在原行为及当前使用时仍有效。请款行内原节点/交付Evidence各按原时点，其他新依据仍核now；同ref承担多个用途分别校验，不以统一now抹掉历史交付。

原保存计价的数量/单价/固定额/扣减和直接Evidence来源按saved.authored_at有效，来源在原计价前可获且原作者具精确读权；新动作重新计算仍走原MethodRegistry的当前依据门，历史等待重核以原调用business_time核原方法输入并仅作固定纯算术对照，不伪装原方法调用。PaymentExecution/PaymentReceipt及旧请款状态更新无独立真实发生点，保有权历史记录/金额，不猜available_at为付款或状态更新时间、不因旧Evidence到期清掉已付或未知占用；原作者授权仍按authored_at。正式请款条件profile升v2，当前query native observed证据门仍独立，不自动迁移旧条件。

从A09接收交付依据时，原关系及作者Evidence按authored_at，混合授权basis保原类型有权读取；DeliveryEvidence和原到货/签收/检验依据按实际occurred_at/arrived_at/authored_at，实际量/检验覆盖量依据按对应原时点。原Shipment可含后续状态更新，其记录依据保历史、发货量依据按dispatched_at，不把全部状态资料倒套原出库时间。各发生点不晚于原source/delivery可获；当前付款节点记录Evidence按其真实authored_at且节点自身仍当前有效，当前native observed/hash仍独立核当前。完整源映射/原保存内容/节点权利仍须独立宿主认证，不因原交付事实而推定可请款或实收。

核当前本企业结算授权/币种/完整原PaymentLedger，订单、客户应收和本企业已成立上游债务分开。空order_refs不免除自身实际义务。到货/请款/核定/到期/实际现金分开；客户或项目业主迟付不免上游欠款，不穿透项目/Owner账户。

request_payment首次允许无既有Obligation/SettlementComponent。按原有效Order/OrderLine和独立实际付款人有权OrderPaymentNode，核具体scope/合同付款节点/覆盖身份及实际交付依据、明确原合同数量/单价/固定价/扣减。缺估值需补信息，不填零；原保存MethodResult摘要/作者读权/来源时点与纯合同金额算术核对，不以成本加成代合同请款。该数学方法仅精确原量×合同单价+固定额−原扣减，同币种不转换/猜价/舍入，不产生权利或清偿。

请款每行保留具体证据、原已登记组成或null，原节点覆盖和完整原PaymentClaim历史排重；原同业务/节点沿原申请续办，不重复造债。若既有组成仅对原真实债务人/本企业应收和已付/非现金抵扣后的已知余量请款，直接银行付款不增加客户现金或二次应收。

authorize_payment核本企业真实自有Account/资金源/实际现金/限制款/完整原预留及待执行，按本企业实际到期应付组成、明确优先级及逐组成金额发起请求。部分付款须明确授权；现金不足要求显式改分配，不按遍历顺序决定。未知原执行先reconcile，已有业务付款续办；非现金预付款抵扣不得再付现金，各组成剩余金额未知不重付。收据身份按原命令/业务/执行/金额/付款状态匹配，重复不能二次入账。

汇总既有义务时，完整component_refs不得重复同一物理组成或其不同版本。每项组成须保原义务、债务人、收款人、资金源及完全一致的debt_ref；无借款关联时双方均为null，有关联时须同一Debt原版本。金额合计一致不能允许混入其他借款的本金、利息或费用；首次订单请款或融资仍不要求预先生成组成。

自有账户pending_execution_refs按物理执行排重；已供应的每项原执行须由本企业付款且account_ref完全等于该原账户，不能用客户来款、空账户或其他账户/版本替代。原执行不得同时归入多个账户，仍保完整组织PaymentLedger与显式execution_refs关联。已终态但账本尚列待核的原记录也沿原ID核对，不自行释放占用、重发或增加可支付现金。

dispute只原已成立义务与具体原问题，不单方免债。seek_finance仅本企业借款人当前权限及原用途/候选产品/披露生成申请草稿，交Bank A02，不要求银行先受理。

completed仅请求/草稿。真实原订单节点/量价/交付/账本/回执生产者、跨动作投影、submit/query、核心一次组成登记/付款/非现金抵扣/清偿和反馈待集成。本批编码未功能验收。
