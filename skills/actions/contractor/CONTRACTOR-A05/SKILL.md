# CONTRACTOR-A05 制定履约排期并采购供应

消费原有效合同或独立准备授权、完整前置/设计/工作方法、当前实际容量及原计划/采购配置。准备授权仅准准备目的；询价、采购另核允许项及完整原已用限额，不解锁施工。只从原明确配置选择分支，不因残留候选提交采购或占用。

Evidence精确ref、双端同钟、非未来并按实际用途核有效窗。当前mandate/要求/资源/依赖/采购限额仍按now；原计划、原有效计划、设计发布、报价及其量价/条款依据按各真实authored_at。旧采购承诺/金额没有逐状态或发生时点，保历史，不把available_at当形成或付款时间；当前完整已用限额另核，不清原付款责任。无内嵌ref的TimeWindow由原有权resolver按请求引用关联；具ref/function_ref记录仍精确核身份，窗口双端同钟。

授权精确核RoleAssignment.function_ref/角色/动作，原作者grant覆盖完整签发scope，当前行动grant覆盖本次scope；不以本次范围替代原作者范围。mixed basis保原类型、读权和原可获，Evidence按真实授权用途窗核。原计划作者须原mandate/设计/依赖/所用方法/窗口/资源及目标量/投入依据读权，来源不晚于签发；原报价作者须原条款/要求/量价依据读权和签发前可获，条款原窗口与现在使用窗独立。

plan/revise_plan核原有权计划作者、设计发布/用途/版本、局部唯一任务键、目标量与适用方法/生产率、窗口/资格与实际地点。前置按原责任方保留，循环依赖返回等待且不放行；已排前置必须先于后续窗。任务范围/数量仅计划，原人力/设备池和已占用容量按唯一身份逐池核算，父子同方法范围不重复计量。不推测跨区调动；修订仅转换原有效计划已占用的对应资源，其他承诺保留。

任务须同时属于本次authorized_scope和原计划scope。WorkMethod/采购权限/产品地点规则可有合法较广适用范围，linked有权读取后另核覆盖实际任务、完整本次采购或对应要求，不把宽来源当扩权。当前MethodRegistry独立计算保持；原循环首门仍在容量调用前，原容量冲突仅走既有已认证纯算术比较，不冒充原方法调用或追加旧方法审计。

request_quote可无报价，但须原产品/数量/交付与现场接收窗、地点、检验/付款条件及真实可询价供应商；无可询价主体保持等待。accept_supply_offer仅接受输入中当前有效报价，同源供应商/买方/付款人/条款/批次数量与价格/交期/地点/检验付款规则整体绑定，原明确替代权不可省略。己方采购责任actor/function及完整条款摘要另核，准备采购不得超原限额；原已存在采购承诺沿原订单查询，不重造。
