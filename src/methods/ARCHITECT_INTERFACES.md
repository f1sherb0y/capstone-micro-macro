# 原作者接口引用一致性

`micro.architect.original_interface_reference_consistency:1` 仅核对已授权接收的建筑方案、专业/造价/供应结论、接口和开放问题的引用关系。

输入明确提供原对象、对应规范 JSON 内容 SHA-256、方案版本、接口集合、完整未决问题集合及来源和证据引用。方法重新计算规范 JSON 摘要，并核对集合覆盖、原方案版本、接口输入和问题保留。重复、缺失、内容变化、跨方案或原开放问题被关闭时，报告保留原输入并给出 `unknown` 及明确问题。

`ok` 只说明这些引用和内容保持一致。未知或冲突的原专业结论不被修改，不因引用一致而变成技术通过。作者权限、实际来源、接收时序、隐私和独立整合委任由原角色处理器及独立宿主校验。方法不审批方案、不确认技术兼容、不推他人同意、不关闭问题、不生成正式整合版本。
