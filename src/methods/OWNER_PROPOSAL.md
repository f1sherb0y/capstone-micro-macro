# Declared private proposal checks and selection, version 1

Scale checks compare supplied known endpoints against supplied inclusive limits
using exact fractions and identical units. Unknown endpoints remain unknown and
require explicit unresolved issues in the consuming action. A non-applicable
scale carries the same authorized Rule on both endpoints; it does not become zero.
Asset type, purpose and intervention applicability are sourced host projections.
The method does not infer building area from road, bridge or service demand.

Private candidates are selected by an explicit ascending ordinal priority under
the declared maximum number of briefs, current uncommitted/unrestricted review
cash and point-in-time available management effort. Each candidate has explicit
nonnegative study costs and effort. Sort only for stable presentation. When an
equal-priority group cannot fit together, report ambiguity; do not choose a subset
using incidental order, invented utility or a hidden optimization policy.
An individually infeasible candidate is excluded; a lower-priority feasible
candidate can still be considered. The maximum supported candidate/brief count
is 64. The host must explicitly supply a different method outside this domain.

These are mathematical comparisons of declared facts and policy, not calibrated
demand forecasts, land valuations, engineering designs or financial models. All
outputs remain private proposal drafts. Nothing is spent, reserved, licensed,
financed or established as a formal project by these methods.
