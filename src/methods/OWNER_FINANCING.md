# OWN-A05 本地资金计划方法

本方法仅核算明确提供的合成或授权事实，不生成银行条款，也不建立正式账本。

现金日历复用已有精确逐来源累计算法：期初为同版实际账户余额减受限金额；加入有明确批准依据且已核验条件的未来收入，在原时点扣除跨项目现有未清义务和本计划支出。逾期义务在当前时点保留扣款，不以未来放款消除原迟付。forecast、received、cancelled 不重复记为未来到账。不同来源不互相弥补缺口，同币种不代表可以转账。

报价评估仅支持完整、固定、明确列出的全额提款本金、还本、利息及费用时序。报价全部字段及这些规则必须引用同一报价版本；累计还本不得超过已提款本金，总提款及总还本均等于该报价的本金。每项费用和现金流按唯一身份只计一次。现金日历可模拟报价的条件性流入和还款，结果不是提款许可或到账。

贷款期限保留来源的左闭右开或两端闭合边界，每笔现金流必须落在原期限内；不为接线改写到期时间。账户地区与项目地区不同时，必须有该账户明确提供的项目地区许可；缺少许可仍返回 unsupported，不复制余额、不推断跨账户转账能力。

报价选择排除名义利息和费用合计超出明确费用上限的候选，再按业主提供的整数优先级升序选择。同级并列须补充选择依据，不推断最低费用偏好。金额用 Fraction 保持十进制传输精度，不依赖 Decimal 全局精度。原始费用、本金和完整时序保留于宿主审计。

支持域为最多 64 个明确来源/报价、单币种和同一业务时钟。禁止自行换汇、跨地区复制余额、跨账户汇总、猜测利率或缺失数据。浮动利率、循环授信、部分提款等须使用相应已注册方法，当前缺少时返回 unsupported；缺少已知方法所需事实返回 needs_information。

现实信贷、税费或法域模型尚未校准。两方独立接受、正式融资安排、债务本金、现金到账、付款和执行回执均由正式入口决定。
