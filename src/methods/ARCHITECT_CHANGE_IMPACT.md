# 原声明变更影响差额

`micro.architect.declared_change_impact@1` 仅计算拟议总额减原总额、拟议工期减原工期。
每个输入保原变更内容摘要、原数值依据对象及全部已知数值 Evidence 引用；金额同币种、工期同时间单位，不换算、不舍入。
原值及拟议值须非负，差额可正可负。成本和工期分别计算，任一对应输入未知则该差额保持未知，缺失引用合并保留；完整输入证据保留原未知原因。

支持时间单位为 s、min、h、day、week、month、year；仅同单位相减，不推断工作日、日历、关键路径或工期责任。
原值和拟议值必须由独立实际来源证明覆盖同一范围、成本口径和时间口径。输入数值声明不证明预测正确。
方法只具数学依据，不估计市场价格、生产率、物理性能、额外工作、费用权利或使用许可。
